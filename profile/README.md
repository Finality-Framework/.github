# Finality Framework  
## Introduction
Finality Framework is a tool suite for _Age of History 3_ modding.   

## Products  
[Finality Manager](https://github.com/Finality-Framework/manager/) - organize your mods easily,and even more.  
[Finality Loader](https://github.com/Finality-Framework/loader/) - allows you to load external codes(We call them plugins) into AoH3.
